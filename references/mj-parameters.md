# MJ参数与P码

核对日期：2026-09-26。以下为官方页面核对结果；版本兼容会变化。普通写词不要反复研究整套MJ文档，使用这里的保守参数即可。遇到未知版本、报错、用户询问最新功能或需要未列参数时，再查相应官方页面；不能验证时省略不确定参数并说明，不猜。

## 参数尾部

所有描述写在前，参数集中放末尾；参数之间留空格，不把说明文字夹进参数。默认只放有实际作用的参数，不整段粘贴历史博主尾缀。

| 参数 | 本skill的用法 |
|---|---|
| `--ar 16:9` | 横屏默认；用户要求其他比例时更改。比例不是分辨率。 |
| `--p` | 应用MJ里默认选定的个性化／情绪板；仅在用户明确采用默认项时使用。 |
| `--p` 后接真实代码/ID | 应用用户指定的参考；原样保留，不把ID改成数值强度。 |
| `--s` | 风格化控制；与个性化／情绪板合用时也影响其风格施加程度。当前文档范围0–1000，默认100。未要求调强度时通常省略，沿用用户设置。 |
| `--raw` | 可减少MJ默认美化，适合追求更直接的文字控制；不是“写实必开”。B也不自动强加，避免改变用户已有风格。 |
| `--no` | 仅按实际问题排除少量明确对象；先把正面要求写清楚，避免否定“people”却又要人物之类冲突。 |
| `--v` | 用户已指定版本且确认兼容时使用；否则省略，继承其当前设置。 |

来源：[参数位置与语法](https://docs.midjourney.com/hc/en-us/articles/32859204029709-Parameter-List)、[Raw](https://docs.midjourney.com/hc/en-us/articles/32634113811853-Raw)、[Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize)。

## P：选择参考，而不是强度

- Personalization profile通过审美选择等建立偏好；Moodboard通过所选图集组织风格。两者都可由 `--p` 调用，但不是同一项配置。
- 官方示意中profile ID形如pID、moodboard ID形如mID；提交后可转成代码。这些是语法示意，**不是可以放进成品的真实ID**。代码也可能是数字或字母数字串，按不透明标识保留。
- 用户只说“P值提高到500”而未明确含义时，简短确认是在提供代码，还是想增强风格；不要直接把它解释为 `--p 500` 或擅自换成 `--s 500`。用户已明确写 `--p 500` 作为代码时不要仅因是数字就误判。
- P已在MJ网页选定时，正文不写 `--p` 也可沿用网页启用的配置。本skill不得声称已经替用户启用；块外提示在MJ保持该配置开启即可。
- ID可随参考更新调用最新版本，历史代码代表相应版本；用户要复现时保留其已确认的代码与其他条件。不能承诺像素级复现。

来源：[Personalization](https://docs.midjourney.com/hc/en-us/articles/32433330574221-Personalization)、[Moodboards](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards)。

## 不混用的概念与版本陷阱

- `--p`不等于 `--sref`。后者是Style Reference；不要把用户给的情绪板图自动改为sref，也不要把sref代码塞进p。用户额外明确指定sref时保持该身份，并核对兼容；不能将“带sref”描述为纯文字出图。
- `--sw`不是P的强度。当前Moodboards文档说明不能与 `--sv`、`--sw` 合用；不要为B模板附这两个参数。
- `--iw`也不是P权重。不要因用户给了参考图就自动添加。
- 当前官方默认版本为V8.2，但用户可能使用其他版本。V8.2不支持V7的 `--oref`、`--draft`、`--q`，也不支持旧多重提示语法；不要混入通用模板。此skill不处理编辑模型的引用语法，遇到相关请求应先核对官方功能。
- `--raw`是当前官方文档使用的写法，不从旧教程机械复制 `--style raw`。用户有明确旧版本工作流时再按其版本核对。
- 不添加不明profile、风格码、seed、极高quality或niji参数；用户选择真人方向时不自动切换动画模型。

来源：[Version兼容表](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)、[Moodboards兼容说明](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards)。

## 风格强度迭代

用户说P味道太强，先保留代码与主体，只建议降低 `--s`；太弱则可试提高。具体步长结合已有值，小幅对比，不给万能固定数值。若主体本身写漏，先补主体；若参考本身与真人目标冲突，说明冲突而不是无限加词。

官方倾向清晰、简洁的画面描述，细节增加控制、删减增加解释空间。因此A/B词数只是本skill的编辑参考，不是MJ官方最佳长度或已验证的英文优越性结论。纯英文是本用户的输出要求。[Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)
